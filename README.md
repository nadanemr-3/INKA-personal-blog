# INKA — Personal Blog

A personal space where ideas, experiences, and stories become articles.

INKA is a full-stack personal blog built with React, Express, and MySQL.

---

## Tech Stack

**Frontend:** React, JavaScript, Vite  
**Backend:** Node.js, Express  
**Database:** MySQL  
**Authentication:** JWT, bcrypt  
**Image Upload:** Multer  

---

## Project Structure
